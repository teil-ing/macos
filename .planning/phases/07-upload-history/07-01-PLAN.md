  - `@Attribute(.unique) var id: UUID`

Create `teil.ing-client/Services/ThumbnailService.swift`:
- Define as `enum ThumbnailService` (caseless namespace pattern, matching CaptureFeedback convention)
- Static constants: `thumbnailSize = CGSize(width: 64, height: 64)` (32pt @2x), `jpegQuality: CGFloat = 0.75`
- `static func thumbnailsDirectory() throws -> URL` — returns `~/Library/Application Support/teilingClient/thumbnails/`, creating with `withIntermediateDirectories: true`
- `static func saveThumbnail(from cgImage: CGImage, id: UUID) throws -> String`:
  1. Call `thumbnailsDirectory()` for the output directory
  2. Build file URL: `dir.appendingPathComponent("\(id.uuidString).jpg")`
  3. Create `CGContext` at 64x64px, sRGB color space, premultipliedLast alpha, 8 bitsPerComponent
  4. Set `interpolationQuality = .medium` (sufficient for 64px)
  5. Compute center-crop source rect to maintain aspect ratio (aspect-fill):
     - If source wider than square: crop left/right
     - If source taller than square: crop top/bottom
  6. Crop via `cgImage.cropping(to: srcRect)`, draw into context
  7. Get resized image via `context.makeImage()`
  8. Encode via `NSBitmapImageRep(cgImage: resized)` + `.representation(using: .jpeg, properties: [.compressionFactor: jpegQuality])`
  9. Write JPEG data to file URL
  10. Return `fileURL.path` as String
- Define `enum ThumbnailError: Error { case resizeFailed, encodingFailed }`
- Import AppKit (for NSBitmapImageRep), CoreGraphics, Foundation

Refer to research Pattern 1 (SwiftData model) and Pattern 4 (ThumbnailService) for exact implementation details.

Create `teil.ing-client/Services/HistoryStore.swift`:
- Import SwiftData, SwiftUI, Foundation
- Define `@MainActor final class HistoryStore: ObservableObject` (matches PreferencesStore convention — ObservableObject, not @Observable)
- `@Published private(set) var entries: [HistoryEntry] = []`
- Private stored property: `let container: ModelContainer`
- Computed property: `private var context: ModelContext { container.mainContext }`
- `init(container: ModelContainer)` — store container, call `fetchEntries()`
- `func fetchEntries()`:
  - Create `FetchDescriptor<HistoryEntry>(sortBy: [SortDescriptor(\.timestamp, order: .reverse)])` (newest first)
  - `entries = (try? context.fetch(descriptor)) ?? []`
- `func addEntry(shareURL: String, thumbnailPath: String, timestamp: Date)`:
  - Create HistoryEntry, `context.insert(entry)`, `try? context.save()`
  - Call `evictOldEntriesIfNeeded()`
  - Call `fetchEntries()` to refresh @Published array (Pitfall 2: manual fetch required after mutation)
- `func delete(_ entry: HistoryEntry)`:
  - Capture `entry.thumbnailPath` before deletion
  - `context.delete(entry)`, `try? context.save()`
  - Call `fetchEntries()`
  - Delete thumbnail file via `FileManager.default.removeItem(atPath:)` — file deletion AFTER DB delete (orphaned file is safer than dangling DB record, per Pitfall 3)
- `func clearAll()`:
  - Capture all `entries.map(\.thumbnailPath)` before deletion
  - `try? context.delete(model: HistoryEntry.self)`, `try? context.save()`
  - Call `fetchEntries()`
  - Delete all captured thumbnail file paths
- Private `func evictOldEntriesIfNeeded()`:
  - Fetch all entries sorted oldest-first (`.forward`)
  - If count > 50, delete excess entries (prefix `count - 50`) from context
  - Save context
  - Delete evicted thumbnail files from disk
