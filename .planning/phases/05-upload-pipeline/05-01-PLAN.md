<task type="auto">
  <name>Task 2: Create UploadService actor with serial queue, retry, multipart POST, clipboard, and browser</name>
  <files>teil.ing-client/Services/UploadService.swift</files>
  <action>
Create `teil.ing-client/Services/UploadService.swift` as a Swift `actor` with `static let shared = UploadService()`.

**Serial queue via chained Task pattern:**
- Private properties: `uploadTask: Task<Void, Never>?`, `pendingCount: Int = 0`
- `failedCapture: CaptureResult?` (private(set)) — retained for Retry; cleared on next `enqueue` call
- `lastError: UploadError?` (private(set)) — most recent error for popover display; cleared on next successful upload or enqueue

**Public API:**
- `func enqueue(_ capture: CaptureResult, onFeedback: @MainActor @Sendable @escaping (UploadFeedbackEvent) -> Void)` — increments `pendingCount`, captures a snapshot of the count, clears `failedCapture`, chains a new Task onto `uploadTask`. The `onFeedback` closure is the mechanism for the actor to drive UI feedback without holding AppKit references. The chained task awaits the prior `uploadTask?.value` first (serialization), then calls `performUpload`.

- `func retry(onFeedback: @MainActor @Sendable @escaping (UploadFeedbackEvent) -> Void)` — if `failedCapture` is non-nil, re-enqueues it via `enqueue`.

**UploadFeedbackEvent enum** (defined at file scope, Sendable):
```swift
enum UploadFeedbackEvent: Sendable {
    case uploadStarted
    case uploadSucceeded(shareUrl: String)
    case uploadFailed(error: UploadError)
}
```

**`performUpload` private method:**
1. Call `onFeedback(.uploadStarted)` — tells AppDelegate to show spinner
2. Read API key: `KeychainService.shared.apiKey`. If nil, call `onFeedback(.uploadFailed(error: .noAPIKey))`, store `failedCapture = capture`, return.
3. Convert CGImage to PNG: `let rep = NSBitmapImageRep(cgImage: capture.image); guard let pngData = rep.representation(using: .png, properties: [:])`. If nil, fail with `.encodingFailed`.
4. Build multipart request (see below).
5. Call `performWithRetry(maxAttempts: 3)` wrapping `executeUploadRequest`.
6. On success: determine `isLast` by comparing captured pendingCount snapshot with current `pendingCount`. If `isLast`, call `await copyToClipboard(result.shareUrl)` and `await openInBrowser(result.shareUrl)`. Call `onFeedback(.uploadSucceeded(shareUrl: result.shareUrl))`. Clear `lastError`.
7. On failure: store `failedCapture = capture`, store `lastError = error`, call `onFeedback(.uploadFailed(error: error))`.

**`buildMultipartRequest` private method:**
- Boundary: `"Boundary-\(UUID().uuidString)"`
- URL: `https://teil.ing/api/v1/upload`
- Method: POST
- Headers: `Content-Type: multipart/form-data; boundary=\(boundary)`, `X-API-Key: \(apiKey)`
- Timeout: 30 seconds
- Body: standard multipart with field name `file`, filename `screenshot.png`, Content-Type `image/png`
- Do NOT include `stripExif` field — that is Phase 6 per locked decisions
- Return `(URLRequest, Data)` tuple — the request and the body data separately for `URLSession.shared.upload(for:from:)`

**`executeUploadRequest` private method:**
- `let (data, response) = try await URLSession.shared.upload(for: request, from: bodyData)`
- Parse `HTTPURLResponse` status code:
  - 201: decode `UploadResponse` via `JSONDecoder()`, return it
  - 401: throw `.unauthorized`
  - 429: parse `Retry-After` header as Int, throw `.rateLimited(retryAfter:)`
  - 400: throw `.badRequest("Image rejected by server")`
  - Other: throw `.serverError(statusCode)`
- Catch `URLError`: throw `.networkError` with descriptive message (check `.notConnectedToInternet`, `.networkConnectionLost` codes for "No internet connection" message; default to "Could not reach teil.ing")

**`performWithRetry` private method:**
- Loop `1...maxAttempts`, calling the operation closure
- On `.unauthorized`: rethrow immediately (do NOT retry — locked decision)
- On `.rateLimited(let retryAfter)`: sleep for `retryAfter ?? pow(2.0, Double(attempt))` seconds
- On other `UploadError`: exponential backoff `pow(2.0, Double(attempt - 1))` seconds (1s, 2s, 4s)
- On generic error: same backoff
- After all attempts exhausted, throw the last error

**Clipboard and browser helpers (private, inside the actor):**
- `copyToClipboard(_ urlString: String)`: `await MainActor.run { let pb = NSPasteboard.general; pb.clearContents(); pb.setString(urlString, forType: .string) }`
- `openInBrowser(_ urlString: String)`: `await MainActor.run { if let url = URL(string: urlString) { NSWorkspace.shared.open(url) } }`

**Import:** `import AppKit` (for NSBitmapImageRep, NSPasteboard, NSWorkspace)

**Data extension** (private, file scope): `extension Data { mutating func append(_ string: String) { if let data = string.data(using: .utf8) { append(data) } } }` — for clean multipart body building.

**Swift 6 considerations:**
- The actor is NOT `@MainActor` — it runs on its own executor
- All AppKit UI calls go through `await MainActor.run { ... }`
- `CaptureResult` is Sendable (CGImage is thread-safe CF type)
- `onFeedback` closure is `@MainActor @Sendable` — safe to call from actor
