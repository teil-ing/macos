<objective>
Create the capture engine actor and dual-path capture backends (SCScreenshotManager for macOS 14+, SCStream for macOS 13) that can capture fullscreen and region screenshots, exclude the app's own windows from captures, and stitch cross-monitor region captures into a single CGImage.

Purpose: This is the core capture infrastructure that all capture modes (region, fullscreen, window) will use. Without it, no screenshot can be taken.
Output: CaptureEngine actor + ScreenshotCapture + StreamCaptureBridge + CrossMonitorStitcher + CaptureResult model, all compiling under Swift 6 strict concurrency.
</objective>

    **CaptureResult.swift** (new file in new Models/ directory):
    - Create a `struct CaptureResult: Sendable` with properties: `image: CGImage`, `capturedRect: CGRect` (global screen coordinates of what was captured), `timestamp: Date`.
    - CGImage conforms to Sendable already (it is a CoreFoundation type that is thread-safe).

    **CaptureEngine.swift**:
    - Create `actor CaptureEngine` (not @MainActor — capture work should not block UI).
    - Public methods:
      - `func captureRegion(_ rect: CGRect) async throws -> CaptureResult` — takes a global-coordinate CGRect, determines which display(s) it intersects, dispatches capture, returns result. If rect spans multiple displays, captures each display's portion separately and delegates to CrossMonitorStitcher (implemented in Task 2).
      - `func captureFullscreen() async throws -> CaptureResult` — captures the display where the mouse cursor currently is. Use `NSEvent.mouseLocation` to find the current screen, match it to an `SCDisplay`.
    - Private helpers:
      - `func buildFilter(for display: SCDisplay) async throws -> SCContentFilter` — calls `SCShareableContent.excludingDesktopWindows(false, onScreenWindowsOnly: true)`, filters out apps where `bundleIdentifier == Bundle.main.bundleIdentifier`, returns `SCContentFilter(display:excludingApplications:exceptingWindows:)`.
      - `func buildConfig(sourceRect: CGRect?, display: SCDisplay, scale: CGFloat) -> SCStreamConfiguration` — sets `pixelFormat` to `kCVPixelFormatType_32BGRA`, `showsCursor = false`, `capturesAudio = false`. If sourceRect provided, sets `config.sourceRect` in display-local coordinates (subtract display frame origin) and `width`/`height` in backing pixels. If nil sourceRect, captures full display dimensions in backing pixels.
      - `func matchDisplay(_ screen: NSScreen, from displays: [SCDisplay]) -> SCDisplay?` — matches by comparing frame origins (SCDisplay.frame vs NSScreen.frame).
      - `func findCurrentDisplay() async throws -> (SCDisplay, NSScreen)` — uses `NSEvent.mouseLocation` to find which `NSScreen` contains the cursor, then matches to SCDisplay.
    - Availability dispatch: use `if #available(macOS 14, *)` to call `ScreenshotCapture` methods, else call `StreamCaptureBridge`.
    - For multi-display region: detect intersection of rect with each `NSScreen.screens` frame, capture each display's intersecting portion, pass to `CrossMonitorStitcher.stitch()`.

    **ScreenshotCapture.swift**:
    - Create `@available(macOS 14, *) enum ScreenshotCapture` (caseless enum namespace, same pattern as APIValidationService).
    - `static func captureFullscreen(filter: SCContentFilter, config: SCStreamConfiguration) async throws -> CGImage` — calls `SCScreenshotManager.captureImage(contentFilter:configuration:)` and returns the CGImage directly.
    - `static func captureRegion(filter: SCContentFilter, config: SCStreamConfiguration) async throws -> CGImage` — same call, config already has sourceRect set by CaptureEngine.
    - Both methods are simple wrappers — the complexity lives in CaptureEngine's config/filter building.

    **Important implementation notes:**
    - `NSEvent.mouseLocation` and `NSScreen.screens` must be accessed on MainActor. Use `@MainActor` helper or `await MainActor.run { }` inside the actor methods.
    - `SCDisplay` does NOT have `backingScaleFactor` — match SCDisplay to NSScreen by comparing frame origins and use `NSScreen.backingScaleFactor`.
    - sourceRect coordinate conversion: `localX = globalRect.origin.x - display.frame.origin.x`, `localY = globalRect.origin.y - display.frame.origin.y`.
    - config.width/height in pixels: `Int(rect.width * scale)` and `Int(rect.height * scale)`.

    **StreamCaptureBridge.swift**:
    - Create `final class StreamCaptureBridge: NSObject, SCStreamOutput, SCStreamDelegate, @unchecked Sendable`.
    - Private properties: `continuation: CheckedContinuation<CGImage, Error>?`, `stream: SCStream?`.
    - Private static let `captureQueue = DispatchQueue(label: "ing.teil.capture.stream", qos: .userInteractive)`.
    - `func captureOneFrame(filter: SCContentFilter, config: SCStreamConfiguration) async throws -> CGImage`:
      - Uses `withCheckedThrowingContinuation`.
      - Inside: store continuation, create SCStream with filter+config+delegate=self, call `try stream.addOutput(self, type: .screen, sampleHandlerQueue: Self.captureQueue)`, then `stream.startCapture()`. Catch errors and resume continuation with error.
    - `nonisolated func stream(_ stream: SCStream, didOutputSampleBuffer sampleBuffer: CMSampleBuffer, of outputType: SCStreamOutputType)`:
      - Guard `outputType == .screen`.
      - Check frame status via `CMSampleBufferGetSampleAttachmentsArray` — look for `SCStreamFrameInfo.status` == `.complete`. Skip non-complete frames (return early).
      - Extract CGImage SYNCHRONOUSLY inside this callback (CRITICAL — do NOT pass sampleBuffer across Task boundary):
        1. `guard let pixelBuffer = sampleBuffer.imageBuffer`
        2. `let ciImage = CIImage(cvPixelBuffer: pixelBuffer)`
        3. `let context = CIContext()` (or use a stored CIContext for performance)
        4. `guard let cgImage = context.createCGImage(ciImage, from: ciImage.extent)`
      - Capture the continuation reference locally, nil out `self.continuation`.
      - Stop stream asynchronously: `Task { try? await stream.stopCapture() }`.
      - Resume continuation with the extracted cgImage.
    - `nonisolated func stream(_ stream: SCStream, didStopWithError error: Error)`:
      - Resume continuation with error if still non-nil, then nil it out.
    - Add a 10-second timeout: in `captureOneFrame`, after starting capture, spawn a Task that sleeps 10 seconds then resumes continuation with a timeout error if still pending. Use a flag or check continuation == nil to avoid double-resume.

    **CrossMonitorStitcher.swift**:
    - Create `enum CrossMonitorStitcher` (caseless enum namespace).
    - `struct DisplayCapture: Sendable` with `image: CGImage`, `displayFrame: CGRect` (the portion of the display that was captured, in global coordinates), `scale: CGFloat`.
    - `static func stitch(_ captures: [DisplayCapture], totalRect: CGRect) -> CGImage?`:
      - Compute canvas size: `maxScale = captures.map(\.scale).max() ?? 1.0`, `canvasW = Int(totalRect.width * maxScale)`, `canvasH = Int(totalRect.height * maxScale)`.
      - Create `CGContext(data: nil, width: canvasW, height: canvasH, bitsPerComponent: 8, bytesPerRow: 0, space: CGColorSpaceCreateDeviceRGB(), bitmapInfo: CGImageAlphaInfo.premultipliedFirst.rawValue | CGBitmapInfo.byteOrder32Little.rawValue)`.
      - For each capture: compute local position `(capture.displayFrame.origin.x - totalRect.origin.x) * maxScale`, same for Y. Draw `context.draw(capture.image, in: destRect)`.
      - Return `context.makeImage()`.
    - Handle coordinate system: CGContext has origin at bottom-left which matches AppKit's coordinate system. No flip needed.

    **project.yml update:**

    - Run `xcodegen generate`.

    - Mark StreamCaptureBridge as `@unchecked Sendable` — the class manages mutable state (continuation, stream) but access is serialized through the capture queue and the withCheckedThrowingContinuation pattern.
    - Import CoreMedia and ScreenCaptureKit in StreamCaptureBridge.
    - The CIContext can be created once and stored as a static property for better performance, but creating per-call is also acceptable for correctness.
    - For the timeout, use a simple approach: store a Bool `didResume` protected by a lock or use the continuation nil-check pattern (check `continuation != nil` before resuming).
