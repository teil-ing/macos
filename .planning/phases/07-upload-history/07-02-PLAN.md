   - After the existing success handling (stopSpinner, playSound, showSuccessIcon, clear uploadError), add history entry creation:
     ```swift
     // Write history entry — thumbnail generation is synchronous on main actor
     // (CGImage resize at 64px is negligibly fast; no background dispatch needed)
     if let thumbnailPath = try? ThumbnailService.saveThumbnail(from: capture.image, id: UUID()) {
         historyStore.addEntry(
             shareURL: shareUrl,
             thumbnailPath: thumbnailPath,
             timestamp: capture.timestamp
         )
     }
     ```
   - File-first write (ThumbnailService), then DB insert (addEntry) — per Pitfall 3: on thumbnail write failure, the entry simply is not created (no dangling DB record)

- All history operations happen on @MainActor (AppDelegate is @MainActor, HistoryStore is @MainActor, mainContext is @MainActor-bound)
