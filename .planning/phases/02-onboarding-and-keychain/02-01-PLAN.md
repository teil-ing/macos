  <action>
Create the `teil.ing-client/teil.ing-client/Services/` directory.

**KeychainService.swift:**
Create a `nonisolated` struct (NOT an actor — the Security framework calls are synchronous C functions with value-type inputs/outputs, so nonisolated is simplest for Swift 6 strict concurrency). Use `static let shared = KeychainService()` singleton with `private init()`.

Constants: `service = "ing.teil.client"`, `account = "api-key"`. Use `kSecClassGenericPassword` and `kSecAttrAccessibleAfterFirstUnlock`.

Methods:
- `var apiKey: String?` — computed property calling a private `read()` method. Uses `SecItemCopyMatching` with `kSecReturnData: true` and `kSecMatchLimit: kSecMatchLimitOne`. Returns nil if status != errSecSuccess.
- `func save(_ key: String) throws` — calls `SecItemAdd`. If `errSecDuplicateItem`, falls through to `SecItemUpdate`. Throws `KeychainError.saveFailed(OSStatus)` on any other non-success status.
- `func delete()` — calls `SecItemDelete`. No throw needed; if item doesn't exist that's fine.

Define `enum KeychainError: LocalizedError` with `case saveFailed(OSStatus)` and a `errorDescription` computed property that includes the OSStatus code.

All query dictionaries must be local variables (never stored properties) to avoid Swift 6 Sendable issues with CFDictionary.

**APIValidationService.swift:**
Create an `enum APIValidationService` (caseless enum, no instances needed).

Define `enum ValidationResult: Sendable` with cases: `.valid`, `.invalidKey`, `.networkError(String)`, `.serverError(Int)`.

Define a static constant for the validation URL: `static let validationURL = URL(string: "https://teil.ing/api/v1/images")!` — this is a lightweight GET endpoint that returns 200 if the key is valid, 401/403 if not. Use `X-API-Key` header (NOT Bearer token — the teil.ing API uses `X-API-Key` per PROJECT.md).

Method: `static func validate(apiKey: String) async -> ValidationResult`:
- Create a `URLRequest` with the validation URL
- Set `request.setValue(apiKey, forHTTPHeaderField: "X-API-Key")`
- Set `request.timeoutInterval = 10`
- Use `try await URLSession.shared.data(for: request)`
- HTTP 200 → `.valid`
- HTTP 401 or 403 → `.invalidKey`
- Any other HTTP status → `.serverError(statusCode)`
- Catch `URLError` where `.code == .notConnectedToInternet || .code == .networkConnectionLost` → `.networkError("No internet connection. Please connect and try again.")`
- Catch any other error → `.networkError("Could not reach teil.ing. Check your connection and try again.")`

**PermissionService.swift:**
`import ScreenCaptureKit`

Create an `enum PermissionService` (caseless enum).

Method: `static func checkScreenRecordingPermission() async -> Bool`:
- Wrap `SCShareableContent.excludingDesktopWindows(false, onScreenWindowsOnly: false)` in a Task with an 8-second timeout (per research pitfall 3 — SCShareableContent can hang).
- Use `withTaskGroup` or two competing Tasks: one that calls SCShareableContent, one that sleeps 8 seconds then cancels the first.
- Return `true` if SCShareableContent succeeds, `false` if it throws or times out.

Method: `static func openScreenRecordingSettings()`:
- Opens `URL(string: "x-apple.systempreferences:com.apple.settings.PrivacySecurity.extension?Privacy_ScreenCapture")!` via `NSWorkspace.shared.open(_:)`.
- Must be called on MainActor (add `@MainActor` annotation).

All types must be `Sendable` for Swift 6 strict concurrency.
