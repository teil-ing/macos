**WindowSelectionCoordinator.swift — new file:**

Create `teil.ing-client/Services/WindowSelectionCoordinator.swift`. This mirrors OverlayCoordinator but for window selection instead of region drag.

```swift
@MainActor
final class WindowSelectionCoordinator {
```

Properties:
- `private var overlayWindows: [(NSWindow, WindowSelectionOverlayView)] = []`
- `private var cachedWindows: [SCWindow] = []` — fetched ONCE before showing overlay to avoid latency in hover loop (per research Pitfall 6)
- `private var cameraCursor: NSCursor?` — lazy-loaded camera cursor

Public API:
```swift
/// Returns the selected SCWindow, or nil if the user cancelled.
/// If the user clicks on the desktop (no window), returns nil and the second return
/// value `capturedDesktop` is true — caller should trigger fullscreen capture instead.
func beginWindowSelection() async -> WindowSelectionResult?
```

Define a result type:
```swift
enum WindowSelectionResult {
    case window(SCWindow)
    case desktop  // User clicked desktop — caller should fullscreen-capture the display under cursor
}
```

Implementation of beginWindowSelection():
1. Fetch SCShareableContent ONCE: `let content = try? await SCShareableContent.excludingDesktopWindows(false, onScreenWindowsOnly: true)`. Cache windows list filtering: `cachedWindows = (content?.windows ?? []).filter { $0.isOnScreen }` and also filter out the own app's windows by checking `$0.owningApplication?.bundleIdentifier != Bundle.main.bundleIdentifier`.
2. Load camera cursor via `makeWindowSelectionCursor()` (see below).
3. Push camera cursor: `cameraCursor?.push() ?? NSCursor.arrow.push()`
4. Create overlay windows for each screen (same NSWindow config as OverlayCoordinator: `.screenSaver` level, `.canJoinAllSpaces`, `.fullScreenAuxiliary`, `sharingType = .none`, `acceptsMouseMovedEvents = true`, `.borderless`, `.clear` background, `.isOpaque = false`).
5. Pass `self` (or a delegate protocol / closure) to each WindowSelectionOverlayView so the view can call `findWindow(at:)`.
6. Order windows front, make the one under cursor key.
7. Use `withCheckedContinuation` with a `resumed` guard (same pattern as OverlayCoordinator) to bridge callback to async. Each view's `onWindowSelected` callback receives either `.window(SCWindow)` or `.desktop` or `nil` (cancel).

Window hit-testing method (called by overlay views on mouseMoved):
```swift
func findWindow(at cgPoint: CGPoint) -> SCWindow?
```
- Iterate `cachedWindows` front-to-back (SCShareableContent returns front-to-back ordering).
- Return the first window where `window.frame.contains(cgPoint)`.
- Important: cgPoint must be in CG coordinates (top-left origin, y-down). The overlay view converts from AppKit view coords to CG coords before calling this.

Coordinate conversion helpers (on WindowSelectionCoordinator since they need primaryScreenHeight from NSScreen.screens which is MainActor):
```swift
func appKitPointToCG(_ appKitPoint: CGPoint) -> CGPoint {
    guard let primaryHeight = NSScreen.screens.first?.frame.height else { return appKitPoint }
    return CGPoint(x: appKitPoint.x, y: primaryHeight - appKitPoint.y)
}

func cgFrameToAppKit(_ cgFrame: CGRect) -> CGRect {
    guard let primaryHeight = NSScreen.screens.first?.frame.height else { return cgFrame }
    let appKitY = primaryHeight - cgFrame.maxY
    return CGRect(x: cgFrame.origin.x, y: appKitY, width: cgFrame.width, height: cgFrame.height)
}
```

Camera cursor loader (private method):
```swift
private func makeWindowSelectionCursor() -> NSCursor
```
- Load from HIServices path: `/System/Library/Frameworks/ApplicationServices.framework/Versions/A/Frameworks/HIServices.framework/Versions/A/Resources/cursors/screenshotwindow`
- Read `info.plist` for hotspot (`hotx`, `hoty`)
- Read `cursor.pdf` as NSImage
- Fallback to `.arrow` if path doesn't exist (future macOS versions)
- Per research Pattern 5

Tear-down method:
```swift
private func tearDown() {
    NSCursor.pop()
    for (window, _) in overlayWindows {
        window.orderOut(nil)
        window.close()
    }
    overlayWindows = []
    cachedWindows = []
}
```

**WindowSelectionOverlayView.swift — new file:**

Create `teil.ing-client/Views/WindowSelectionOverlayView.swift`. This is an NSView that covers one display and handles hover-highlight and click-to-select.

```swift
final class WindowSelectionOverlayView: NSView {
```

Properties:
- `var owningScreen: NSScreen?`
- `var onWindowSelected: ((WindowSelectionResult?) -> Void)?` — callback: .window(SCWindow), .desktop, or nil (cancel)
- `weak var coordinator: WindowSelectionCoordinator?` — for findWindow(at:) and coordinate conversion
- `private let dimmingLayer = CAShapeLayer()` — evenOdd fill, dims everything except highlighted window
- `private var highlightedWindow: SCWindow?` — currently hovered window

Setup:
- `wantsLayer = true`
- dimmingLayer with `fillRule = .evenOdd`, `fillColor = NSColor.black.withAlphaComponent(0.35).cgColor` (same opacity as SelectionOverlayView)
- Initial path: entire view dimmed (no hole)
- Add NSTrackingArea with options `[.mouseMoved, .activeAlways, .inVisibleRect]` — MUST use `.activeAlways` not `.activeInKeyWindow` since the overlay may not be key window during hover (per research Pitfall 5)
- `acceptsFirstResponder` returns `true`

mouseMoved handler:
1. Convert event location from window coords to view coords: `convert(event.locationInWindow, from: nil)`
2. Convert view point to global AppKit screen coords: use `window.convertPoint(toScreen:)` on the view point
3. Call `coordinator?.appKitPointToCG(screenPoint)` to get CG coordinates
4. Call `coordinator?.findWindow(at: cgPoint)` to get the SCWindow under cursor
5. If the hovered window changed, update `highlightedWindow` and redraw:
   - If an SCWindow is found: convert its CG frame to AppKit global coords via `coordinator?.cgFrameToAppKit()`, then convert that global rect to THIS view's local coordinates (subtract window.frame.origin), then update dimming path with that rect as the "hole"
   - If no SCWindow found (desktop): dim everything (no hole)

Dimming path update (reuses SelectionOverlayView pattern):
```swift
private func updateDimmingPath(highlightRect: CGRect?) {
    let path = CGMutablePath()
    path.addRect(bounds)
    if let rect = highlightRect, rect.width > 0, rect.height > 0 {
        path.addRect(rect)  // inner hole — this area stays bright
    }
    CATransaction.begin()
    CATransaction.setDisableActions(true)
    dimmingLayer.path = path
    CATransaction.commit()
}
```

mouseDown handler:
- Convert click point to CG coordinates (same as mouseMoved)
- Call `coordinator?.findWindow(at: cgPoint)`
- If SCWindow found: `onWindowSelected?(.window(scWindow))`
- If nil (desktop): `onWindowSelected?(.desktop)`

keyDown handler:
- If keyCode == 53 (Escape): `onWindowSelected?(nil)` — cancel

resetCursorRects: do NOT call `addCursorRect` here — the cursor is managed by WindowSelectionCoordinator push/pop.

Important implementation notes:
- The coordinate conversion from SCWindow.frame (CG: top-left origin, y-down) to AppKit view coords is critical. Use the coordinator's helper, then subtract the overlay window's frame origin to get view-local coordinates.
- The view-local conversion for the highlight rect must account for the overlay window's position on its screen. If the overlay window's frame is at `screen.frame` in global AppKit coords, then `localRect = CGRect(x: globalAppKitRect.origin.x - window.frame.origin.x, y: globalAppKitRect.origin.y - window.frame.origin.y, width: globalAppKitRect.width, height: globalAppKitRect.height)`.

2. Add new capture flow method (mirrors startRegionCapture/startFullscreenCapture pattern):
```swift
private func startWindowCapture() {
    closePopover()

    Task { @MainActor in
        // Same 200ms delay as other capture modes (per locked decision)
        try? await Task.sleep(for: .milliseconds(200))

        guard let selection = await windowSelectionCoordinator.beginWindowSelection() else {
            // User cancelled (Escape) — no capture, no feedback
            return
        }

        // Give compositor one frame to clear overlay windows
        try? await Task.sleep(for: .milliseconds(50))

        switch selection {
        case .window(let scWindow):
            do {
                let result = try await captureEngine.captureWindow(scWindow)
                lastCaptureResult = result
                // Flash at the window's position (convert CG frame to AppKit for CaptureFeedback)
                let appKitRect = windowSelectionCoordinator.cgFrameToAppKit(scWindow.frame)
                await CaptureFeedback.showCaptureFlash(in: appKitRect)
                CaptureFeedback.playCaptureSound()
                CaptureFeedback.showSuccessIcon(on: statusItem)
            } catch {
                showCaptureError(error.localizedDescription)
            }

        case .desktop:
            // Per user decision: clicking desktop = fullscreen capture of that display
            do {
                let result = try await captureEngine.captureFullscreen()
                lastCaptureResult = result
                await CaptureFeedback.showCaptureFlash(in: result.capturedRect)
                CaptureFeedback.playCaptureSound()
                CaptureFeedback.showSuccessIcon(on: statusItem)
            } catch {
                showCaptureError(error.localizedDescription)
            }
        }
    }
}
```
